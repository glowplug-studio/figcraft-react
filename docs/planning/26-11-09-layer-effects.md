## State, hazards and rollback

Keep effects ordered in immutable node snapshots. Derive masks, outlines and render bounds from those snapshots. Keep picker, preview and surface reservations ephemeral. Integrate effect margins into page culling, group isolation, mask areas and nested backdrop reads. Preserve colour-space handling and account for live memory during asynchronous image work. Rendering a shadow with a CSS box-shadow or applying a single blur to the page would lose the native silhouette, compositing order and backdrop.

Use the existing sequential, single-agent workflow in the canonical checkout. The source baseline for rollback is 87ced5f. Verify and commit each implementation checkpoint separately.
