## Execution checkpoint

Start at `src/engine/file-format.ts::decodePublishedLibrary` and `encodeFigcraftBlob`. The current local reader uses one fixed unpacked budget. Apply the host's smaller budget only to manifest, library snapshot and referenced images, as native `read_library_within` does. Existing local files retain their current limit. Browser storage transport has a separate ceiling. Use the upstream-produced fixtures in `tests/fixtures/native-component-library-v1.figcraft` and `tests/fixtures/native-published-library.figcraft`. Check the version, component identity and absence of the original drawing in the uploaded holder before wiring authorisation and persistence.
