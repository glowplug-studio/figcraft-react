| Order | Implementation | Required evidence |
|---|---|---|
| 1 | Add an operator setting, off by default, with view, comment and edit access. An authenticated directory request lists files with at least one coded owner link. Original publication grants and team grants do not qualify. Return the updated time, current participant count, name and configured role. Sort by updated descending then name ascending and truncate to 500. | Compare disabled, empty, unpublished, published-only, shared and unshared fixtures. Verify ordering at the 500th entry, membership after individual revocation and absence of credentials and owner metadata. |
| 2 | Resolve a tokenless directory link into one grant per file and sharing interval. Serialise issuance with management, respect the existing link limit and retain the issued credential across restarts. Reuse the existing guest admission, Storage and revocation path. | Concurrent lookups return one credential. An independent guest joins with the configured access. Stopping sharing disconnects the guest and denies further reads. Restarting sharing issues a different credential. Switching the configured role or turning the directory off invalidates the old credential permanently, including when the original setting returns before another lookup. |
| 3 | Show the configured server’s directory under Home → Online alongside device-owned files. Handle empty, unavailable and disabled states, including a host change. Support opening entries and copying native and optional browser links. Put the tokenless invite in the web URL fragment. | Two signed-in browser accounts exercise refresh, join, role restrictions, copy, owner stop, guest disconnect and a fresh join. Verify no team token appears in listing, clipboard or browser URL. Match native validation for IDs, names and web URLs. |
| 4 | Update the ownership matrix and tracker, then run the local migration, security, provider, native reference and production browser gates. | Record source revision, concrete case results and remaining dependencies. The first ordered-edit fixture in row 14 must also exercise a team guest. |
