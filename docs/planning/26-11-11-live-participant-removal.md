The [transport](../../original/figcraft/crates/collab-net/src/hub.rs) separately allows a server operator who authenticated a dedicated management connection to remove a participant. Merely opening a file with operator management enabled does not confer the editor’s owner capability.

4. The People menu and avatar action use the async command. Validate the target client and show the native success or refusal. Preserve the local copy on removal. A lost Realtime event must return the same reason through the existing authenticated heartbeat.
