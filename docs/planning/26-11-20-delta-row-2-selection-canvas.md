Evidence already read: native `crates/doc/src/geometry.rs::{marquee_select,marquee_children,marquee_touches,path_touches_rect,marquee_deep,marquee}` and `crates/engine/src/marquee_behaviour_tests.rs`. A plain marquee selects each top-level layer it touches whole, except a frame with children or a section with its contents shown: enclosed, it is selected itself; partly covered, the marquee takes the layers in it that it touches. The frame the drag started in is selected only when the marquee also takes another top-level frame whole (then it comes whole); otherwise only the layers in it the marquee touches. Selecting any frame or section whole keeps the marquee at the top level: no frame opens and a partly covered one comes whole. An empty frame is selected on touch; components, instances, board items and sections with hidden contents only when enclosed. A rotated rectangle, ellipse, polygon, star, line or vector is touched by its outline in page space, an unrotated one by its box. The port's `canvas-selection.ts::{marqueeWithin,marqueeSelection}` has the older rule: a drag begun in a top-level frame selects only that frame's children, and a partly covered frame is skipped.
