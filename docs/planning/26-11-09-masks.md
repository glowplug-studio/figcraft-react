# Alpha, vector and luminance masks

## Scope and dependencies

Appearance roadmap row 6. The existing immutable editor, hierarchy commands, native archive, geometry hit tests and paint compositor provide the dependencies. A mask affects successive siblings within the same parent. It affects hit testing, group bounds and what the browser draws. Treating it as a clip on a single child would lose these behaviours. Use the current blend release as the rollback point.

## State, rendering and access

Persist mask properties on local native layers. Ephemeral selection and hover remain engine-owned. Compute paint runs in the render or geometry layer and share native boundary rules. Keep an unmasked fast path for 10,000-layer traversal. Bound raster work by transformed mask and content extents and visible device pixels, including antialias margins. Never allocate a document-sized bitmap for a small visible mask. Cap nested allocations and release temporary backing stores when an image decode cancels or the document changes. Preserve z-order during suspended image/pattern paints. Anchor tests in native samples and independently computed coverage values.

The signed-in Next.js host supplies validated access through the provider-neutral adapter. The feature adds properties to existing local design documents. It introduces no new backend entities, grants, storage objects, subscriptions, RLS policies or retention rules. Continue using device recovery and native download. Check the scoped Supabase project and exercise real local Auth before release. Cloud-file ownership, live collaboration and access revocation remain in their respective slices.

Graphics exports, text glyph outlines, effects inside masks and reversed auto-layout stacking require their owning implementations. Carry explicit matrix rows for those integrations and close them before final publication. The current slice includes all supported layer kinds.

The native renderer's Cargo.lock pins tiny-skia 0.12.0. The SHA-256 of its published crate was checked against the lockfile. Mask::from_pixmap uses encoded channel values weighted by 0.2126, 0.7152 and 0.0722, multiplied by alpha, clamped and rounded upwards to one byte. Canvas getImageData supplies straight RGBA, so convert coverage once. Use opaque primary and semitransparent fixtures to detect accidental linear-light conversion or double multiplication.
