# Planning

Dated port-conversion plans belong here once feature porting begins. Name them `YY-MM-DD-<description>.md`.

Every active plan starts with an `Execution checkpoint` table containing:

- overall status and active phase;
- upstream baseline, branch and last verified commit;
- completed work and tests last passed;
- files currently in progress;
- blockers;
- exact next action;
- last-updated time.

Update the checkpoint after each phase and immediately before stopping so another agent can verify the repository state and resume without repeating completed work.
