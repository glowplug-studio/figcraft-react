### Replacement room and client identity

A saved server restart keeps its room identity, journal, processed batch IDs and client namespace. A completely new server for the same drawing may assign the same client number. Native `Client::receive` compares the welcome's session and client ID. On either mismatch it calls `restart`, discards queued user batches and per-client history, then adopts the fresh drawing. It reports one loss per user batch, excludes derived follow-ups and starts allocating IDs from the new document. See the [native client](../../original/figcraft/crates/collab/src/client.rs) and [reconnect cases](../../original/figcraft/crates/collab/src/reconnect_tests.rs).
