**Live admission at `892f67a`.** [Schema 40](../../supabase/schemas/40_live_client_ids.sql) pairs each new physical grant with a durable client number in one transaction. An unscanned file returns its immutable object to the trusted host and rolls back the provisional grant. The host reads that object and submits its numeric floor. Retried, concurrent and resumed joins use the room lock, the authenticated login and a private per-tab resume digest. Reconnect replaces the old physical connection. Cover the native default of 256 participants, 4,096 hard ceiling, 65,536 remembered clients, reserved maximum client ID, old snapshot users and cross-login isolation. The browser allocator shares the existing branch machinery for layers and document assets. Live branches start 2^24 counters above the existing counters. The native comment fixture produced an identical 904-byte postcard body, 921 bytes framed. Ordered batch authority, presence and the comment UI remain open.
