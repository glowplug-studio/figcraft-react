Auto layout parity

Local release 0.50.0 verified on 9 November 2026. Reference Figcraft 3839fe4a0cb4897c1fed1fb03e0b60e191ff61cb. React dbc35f4 on prompt/full-figcraft-port. The local layout verification gate passed.

Tests used the pinned Rust engine, strict TypeScript, Vitest, local Supabase Auth and Playwright Chromium against the production Next.js build. At dbc35f4, 1,823 pure tests and both local Auth checks passed. Full Chromium passed 247/247 at 0306139. The version 0.50.0 run initially stopped on an obsolete first-layer value assertion for mixed selections. The revised check verifies both the mixed display and the first layer’s actual position. The four focused checks and all 250 production Chromium tests passed. The full run took 515.8 seconds with zero skips, failures or flaky tests. The four 10,000-node gesture checks measured 4.4–11.4 ms p95, with at most 965,712 bytes of retained JavaScript heap growth after collection. See the dated verification record and signed-in browser workflows.
