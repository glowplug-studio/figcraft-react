Boundaries and unfinished evidence

Browser account identity substitutes for native owner bearer tokens. Caller-provided owner strings are rejected except keyed share/unshare; valid operator sharing resolves the actual immutable owner on the server. The URL operator key never elevates other actions. Native LAN listening and binary socket interoperability remain documented browser limitations.

The helper reuses one generated link credential across lock-contention retries. A provider integration case commits a real grant, simulates loss of its successful response, proves no automatic retry, then proves an explicit retry creates a distinct grant. This is simulated response loss above a real local database, not packet loss on a real browser connection. Contention, duplicate-server and failed-ack properties retain Medium confidence where only contract/provider evidence exists.
