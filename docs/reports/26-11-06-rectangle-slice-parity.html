Scope and environment

Create a rectangle in a fresh unsaved document, display selection, undo/redo, constrained pointer drawing and authenticated host access. Canvas2D replaces native rendering for this subset. Full native UI, save/load, other shapes, snapping, navigation, existing-layer manipulation and collaboration are outside scope; reload discards the local document. No Rust executes in the React build or tests.
